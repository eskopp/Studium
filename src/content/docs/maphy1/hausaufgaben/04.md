## Aufgabe 1

Man entscheide für die folgenden Funktionen $f : D \subseteq \mathbb{R} \to \mathbb{R}$, ob sie injektiv (auf ihrem jeweiligen Definitionsbereich) sind. Die Antwort ist zu begründen.

- (a) $f(x) = 3x + 1$, $D = \mathbb{R}$
- (b) $f(x) = x^2$, $D = [0, \infty)$
- (c) $f(x) = x^2$, $D = \mathbb{R}$
- (d) $f(x) = mx + n$, $D = \mathbb{R}$, $\quad m, n \in \mathbb{R}$

### Lösung

Prüfung auf Injektivität: $\forall x_1, x_2 \in D : f(x_1) = f(x_2) \Rightarrow x_1 = x_2$

**a)** $f(x) = 3x + 1$, $D = \mathbb{R}$

$$
\begin{aligned}
3x_1 + 1 &= 3x_2 + 1 && \mid -1 \\
3x_1 &= 3x_2 && \mid : 3 \\
x_1 &= x_2
\end{aligned}
$$

Da aus $f(x_1) = f(x_2)$ folgt $x_1 = x_2$, ist $f$ **injektiv**.

**b)** $f(x) = x^2$, $D = [0, \infty)$

$$
x_1^2 = x_2^2 \ \mid \sqrt{\ } \quad\Rightarrow\quad x_1 = x_2
$$

Da aus $f(x_1) = f(x_2)$ folgt $x_1 = x_2$, ist $f$ **injektiv**.

**c)** $f(x) = x^2$, $D = \mathbb{R}$

Behauptung: Die Funktion ist nicht injektiv. Beweis durch Gegenbeispiel:

$$
x_1 = -1 \mapsto 1, \qquad x_2 = +1 \mapsto 1
$$

Die Funktion ist unter $D$ **nicht injektiv**.

**d)** $f(x) = mx + n$, $D = \mathbb{R}$, $m, n \in \mathbb{R}$

Problemfall: $m = 0$, dann ist $f(x) = 0 \cdot x + n = n$. Die Funktion ist nicht injektiv, da $m = 0$ sein kann.

Für $m \ne 0$:

$$
m x_1 + n = m x_2 + n \quad\Rightarrow\quad m x_1 = m x_2 \ \mid : m \quad\Rightarrow\quad x_1 = x_2
$$

Für $m \ne 0$ ist die Funktion injektiv.

## Aufgabe 2

Man entscheide für die folgenden Funktionen $f : A \to B$, ob sie surjektiv sind. Die Antwort ist zu begründen.

- (a) $f(x) = 3x + 1$, $A = B = \mathbb{R}$
- (b) $f(x) = mx + n$, $A = B = \mathbb{R}$, $\quad m, n \in \mathbb{R}$
- (c) $f(x) = x^2$, $A = B = \mathbb{R}$
- (d) $f(x) = x^2$, $A = \mathbb{R}$, $B = [0, \infty)$

### Lösung

Prüfung auf Surjektivität: $\forall y \in B\ \exists x \in A : f(x) = y$

**a)** $f(x) = 3x + 1$, $A = B = \mathbb{R}$

$$
3x + 1 = y \ \Rightarrow\ 3x = y - 1 \ \mid : 3 \ \Rightarrow\ x = \frac{y-1}{3}
$$

Zu jedem $y$ gibt es ein $x$, die Funktion ist **surjektiv**.

**b)** $f(x) = mx + n$, $A = B = \mathbb{R}$, $m, n \in \mathbb{R}$

Für $m \ne 0$:

$$
mx + n = y \ \mid -n \ \Rightarrow\ mx = y - n \ \mid : m \ \Rightarrow\ x = \frac{y-n}{m}
$$

Für $m = 0$ ist $f(x) = n$. Die Funktion ist bei $m = 0$ nicht surjektiv. Bei $m \ne 0$ ist die Funktion surjektiv. Insgesamt ist die Funktion **nicht surjektiv**.

**c)** $f(x) = x^2$, $A = B = \mathbb{R}$

$$
x^2 = y \ \mid \sqrt{\ } \quad\Rightarrow\quad x = \sqrt{y}
$$

Problem ist zum Beispiel $y = -4$. Dann ist $x$ nicht definiert, denn $\sqrt{-4}$ ist keine reelle Zahl. Die Funktion ist **nicht surjektiv**.

**d)** $f(x) = x^2$, $A = \mathbb{R}$, $B = [0, \infty)$

Aus c) folgt $x = \sqrt{y}$. Da $B = [0, \infty)$ ist, ist die Aussage immer wahr. Die Funktion ist im oben genannten Bereich **surjektiv**.

## Aufgabe 3

Von den folgenden Teilmengen $A, B$ der reellen Zahlen zeige man, dass sie gleichmächtig sind. Geben Sie dazu jeweils eine Bijektion $f : A \to B$ an.

- (a) $A = (0,1) = \{x \in \mathbb{R} \mid 0 < x < 1\}$, $B = (a,b) = \{x \in \mathbb{R} \mid a < x < b\}$, wobei $a, b \in \mathbb{R}$ mit $a < b$.
- (b) $A = (-\infty, 0]$, $B = [1, \infty)$

### Lösung

Bijektiv heißt surjektiv und injektiv.

**a)** $A = (0,1)$, $B = (a,b)$ mit $a, b \in \mathbb{R}$, $a < b$.

Allgemeine lineare Funktion $f(x) = mx + n$. Gewählt wird

$$
f(x) = (b - a) \cdot x + a \quad\text{mit } a, b \in \mathbb{R}
$$

*Injektiv:* $\forall x_1, x_2 \in \mathbb{R} : f(x_1) = f(x_2) \Rightarrow x_1 = x_2$

$$
\begin{aligned}
(b-a) x_1 + a &= (b-a) x_2 + a && \mid -a \\
(b-a) x_1 &= (b-a) x_2 && \mid : (b-a) \\
x_1 &= x_2
\end{aligned}
$$

Damit ist bewiesen, dass die Funktion injektiv ist.

*Surjektiv:* $\forall y \in \mathbb{R}\ \exists x \in \mathbb{R} : f(x) = y$

$$
\begin{aligned}
(b-a) \cdot x + a &= y && \mid -a \\
(b-a) \cdot x &= y - a && \mid : (b-a) \\
x &= \frac{y-a}{b-a}
\end{aligned}
$$

Die Funktion ist surjektiv. Da die Funktion sowohl surjektiv als auch injektiv ist, ist die Funktion **bijektiv**.

**b)** $A = (-\infty, 0]$, $B = [1, \infty)$

$$
f(x) = -x + 1
$$

Die Funktion wurde mit dem CAS erstellt.

*Injektivität:* $\forall x_1, x_2 \in A : f(x_1) = f(x_2) \Rightarrow x_1 = x_2$

$$
\begin{aligned}
-x_1 + 1 &= -x_2 + 1 && \mid -1 \\
-x_1 &= -x_2 && \mid \cdot (-1) \\
x_1 &= x_2
\end{aligned}
$$

Die Funktion ist injektiv im angegebenen Bereich.

*Surjektiv:* $\forall y \in B\ \exists x \in A : f(x) = y$

$$
\begin{aligned}
-x + 1 &= y && \mid -1 \\
-x &= y - 1 && \mid \cdot (-1) \\
x &= -y + 1
\end{aligned}
$$

Die Funktion ist surjektiv im angegebenen Bereich.

## Aufgabe 4

Es sei $f : A \to B$ und $g : B \to C$ sowie $g \circ f : A \to C$ die Verkettung beider Funktionen. Beweisen Sie:

- (a) Ist $g \circ f$ surjektiv, so ist $g$ surjektiv.
- (b) Ist $g \circ f$ injektiv, so ist $f$ injektiv.

### Lösung

$f : A \to B$, $\quad g : B \to C$, $\quad g \circ f : A \to C$

**a)** $g \circ f$ surjektiv $\Rightarrow$ $g$ surjektiv

$$
A \xrightarrow{\ f\ } B \xrightarrow{\ g\ } C
$$

Für beliebiges $c \in C$ gibt es wegen der Surjektivität von $g \circ f$ ein $a \in A$ mit $g(f(a)) = c$. Mit $b = f(a)$, $b \in B$, gilt

$$
g(b) = c.
$$

Also gilt $\forall c \in C\ \exists b \in B : g(b) = c$. Damit ist $g$ surjektiv.

**b)** $g \circ f$ injektiv $\Rightarrow$ $f$ injektiv

$$
g \circ f(a_1) = g \circ f(a_2) \ \Rightarrow\ a_1 = a_2
$$

Das heißt: $\forall a_1, a_2 \in A : \big(g \circ f(a_1) = g \circ f(a_2)\big) \Rightarrow a_1 = a_2$.
